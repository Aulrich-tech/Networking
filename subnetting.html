// 02 — CLASSFUL-STYLE SUBNETTING

Subnetting

Breaking one large network into a fixed number of equally-sized smaller networks — driven by "how many subnets do I need," using a single subnet mask across the whole design.

2ˣ = subnets 2ʸ − 2 = hosts CIDR /8 – /30 Increment = 256 − mask
§1

What subnetting is, and why bother

Subnetting takes one larger network and breaks it into a bunch of smaller networks.

Security

Improved network security through isolation.

Performance

Better network performance and speed; less congestion.

Manageability

Administration is a breeze and growth is easier to control.

§2

Subnet masks

A subnet mask is a 32-bit value that lets the recipient of IP packets distinguish the network ID portion of an address from the host ID portion. The 1s in the mask mark the network/subnet bits.

DEFAULTS DON'T SHRINK Not every network needs subnets — some just use the default mask. Defaults can only ever be extended, never reduced: Class A can't go below 255.0.0.0, Class B not below 255.255.0.0, Class C not below 255.255.255.0.

§4

Network vs. host addresses

Example: 130.57.1.56 is a Class B address, so the first two octets are the network and the last two are the host.

Plain Class B address

Network address

130.57. → 1000 0010 . 0011 1001

Host address

1.56 → 0000 0001 . 0011 1000

Class B address, subnetted

Network address (unchanged)

1000 0010 . 0011 1001

Subnet | Host address (borrowed from the host portion)

0000 0001 . 0011 1000

To create a subnet, take bits from the host portion and reserve them for the subnet address. Fewer bits are then left for hosts — the more subnets you carve out, the fewer host bits remain.

§5

Classless Inter-Domain Routing (CIDR)

CIDR describes a network by its base address and the number of bits used for the network portion, e.g. 10.0.0.0/8 — 24 bits remain for host numbering, so a maximum of 2²⁴−2 host addresses. The slash counts every masked (1) bit, regardless of class.

RULE The largest subnet mask available, for any class, is /30 — you must always keep at least 2 host bits.

§6

1 Determine # of networks needed, convert to binary 2 Reserve that many bits in the subnet mask, find the increment 3 Use the increment to write out every network range

§7

Subnetting the fast way — 5 questions

Skip the long-hand binary and just answer five questions using powers of two.

1 · How many subnets?

2ˣ = subnets

x = number of masked bits (the 1s). E.g. mask 11100000 → 2³ = 8 subnets.

2 · How many hosts per subnet?

2ʸ − 2 = hosts

y = number of unmasked bits (the 0s). E.g. 11100000 → 2⁵ − 2 = 30 hosts. Subtract 2 for the subnet ID and broadcast address — neither is a valid host.

3 · What are the valid subnets?

256 − mask = increment

E.g. 256 − 224 = 32. Count up in blocks of 32 from zero until you reach the mask value: 0, 32, 64, 96, 128, 160, 192, 224.

4 · Broadcast of each subnet?

Always the number right before the next subnet starts. The 0 subnet's broadcast is 31 (next subnet is 32); the 32 subnet's broadcast is 63 (next is 64). The very last subnet's broadcast is always .255.

5 · What are the valid hosts?

Everything strictly between the subnet address and its broadcast address. E.g. subnet 32 / broadcast 63 → valid hosts are 33–62.

§8

The ANDing process

Given a host address and its mask, AND the two together bit-by-bit to reveal the network address that host belongs to.

Given: 150.5.4.22 /23

Host   150.5.4.22   10010110.00000101.00000100.00010110

Mask  255.255.254.0  11111111.11111111.11111110.00000000

AND                   10010110.00000101.00000100.00000000

Network address: 150.5.4.0 — so host 150.5.4.22 belongs to network 150.5.4.0 (mask /23).

§10

Self-check

You need 10 subnets from a Class C network. How many bits must you borrow?
4 bits (2⁴ = 16 ≥ 10). Borrowing 3 bits only gives 2³ = 8 subnets, which isn't enough.
A subnet mask of 255.255.255.240 supports how many hosts per subnet?
4 host bits remain → 2⁴ − 2 = 14 usable hosts.
What is the increment for a /28 mask, and what are the first three subnets after 0?
256 − 240 = 16. Subnets: 0, 16, 32, 48 …
Why can /24–/30 be used on Class A, B, or C — but /9–/15 only on Class A?
Those prefix lengths fall inside the default network portion of Class B and C (already all network bits by /16 and /24 respectively), so there's no host octet left to borrow from at that boundary.
