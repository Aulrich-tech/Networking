Network Models

How the OSI and TCP/IP models break communication into layers, what each layer is responsible for, which devices live there, and how data is wrapped and unwrapped as it travels from an application to the wire.

OSI · 7 layers TCP/IP · 4–5 layers Encapsulation Demarcation point
§1

Networks & protocols

Network / networking

A data or information network is capable of carrying many different types of communications. Networking is the interconnection of devices to enable resource sharing.

Protocols

A protocol is a set of rules or instructions used to let devices communicate successfully — think of it as the shared language both ends agree to speak.

WATCH FOR Proprietary protocols can only be run by the vendor that developed them — they don't guarantee interoperability across brands the way open, standard protocols do.

§3

Layer-by-layer breakdown

7 · Application — network processes to applications
Provides network services directly to application processes such as email, file transfer, and terminal emulation.
Examples: web browsers (Chrome, Firefox, Edge, Safari), email clients.
End devices: PCs, servers, network printers.
6 · Presentation — data representation
Ensures data is readable by the receiving system: formats and structures data, and negotiates the data-transfer syntax for the application layer.
Common formats: JPG, PNG, GIF, MP3, MP4, DOC, PDF.
5 · Session — interhost communication
Establishes, manages, and terminates sessions between applications.
Rule of thumb: a remote connection = a session.
4 · Transport — end-to-end connections
In charge of the reliable transport of data (TCP and UDP). Concerned with transportation issues between hosts: data-transport reliability, establishing / maintaining / terminating virtual circuits, fault detection and recovery, and flow control.
3 · Network — logical addressing & best-path determination
Provides connectivity and path selection between two hosts, assigns the logical (IP) address, and offers best-effort delivery with no error correction of its own.
Routing protocols: RIP, EIGRP, OSPF, BGP.
Device: routers.
2 · Data Link — direct link control, access to media
Provides reliable transfer of data across the local media: physical (MAC) addressing, network topology, error notification, and flow control.
WAN encapsulation types: HDLC, PPP, Frame Relay.
Device: switches.
1 · Physical — binary transmission
Wires, connectors, voltages, and data rates — the raw transmission medium.
Media: copper, fiber, air.
Standards: Ethernet, EIA/TIA, and the many physical connector types.
§4

Who owns which layer

Layers 5–7

System administrators / system engineers typically own the Session, Presentation, and Application layers — the software and services side.

Layers 1–4

Network administrators / network engineers typically own the Transport, Network, Data Link, and Physical layers — getting bits reliably from host to host.

§5

LAN, WAN & the demarcation point

In a typical path — PC → switch → router → CSU/DSU → internet — everything from the PC through the router sits on the LAN side; everything from the demarcation point outward (through the CSU/DSU and into the ISP cloud) is the WAN side. The demarcation point is where the provider's responsibility ends and yours begins.

Modem / DSL bridge

Converts the ISP's line signal (e.g. DSL) into an Ethernet connection the router can use.

Router / switch / DHCP server

Provides connectivity and best-path selection between hosts, assigns logical (IP) addresses, and offers best-effort delivery — no built-in error correction.

CSU/DSU

Channel Service Unit / Data Service Unit — terminates a digital WAN circuit at the customer's demarcation point.

TCP/IP model

TCP/IP collapses the top three OSI layers into one Application layer, and the bottom two into one Network Access layer. A commonly-taught "updated" TCP/IP model instead keeps Data Link and Physical separate — closer to how real troubleshooting is done.

§7

Encapsulation & de-encapsulation

As data moves down the stack for transmission, each layer wraps the previous layer's output in its own header (encapsulation). The receiving host reverses the process, stripping headers as data moves up the stack (de-encapsulation) — like a package getting wrapped for shipping and unwrapped on arrival.

§8

Self-check

Which layer establishes, manages, and terminates a session?
Layer 5 — Session. Remember: a remote connection = a session.
A packet becomes a frame at which layer, and what gets added?
Layer 2, Data Link — a frame header (and trailer, medium dependent) is added around the Layer‑3 packet.
Who typically manages Layers 1–4 vs. Layers 5–7 in an organization?
Layers 1–4: network administrators / network engineers. Layers 5–7: system administrators / system engineers.
What are the three stated advantages of the OSI layered model?
Intervendor operability, ease of troubleshooting, and ease of understanding.
